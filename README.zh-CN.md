# NoType

macOS 上的 AI 语音输入工具。按一下快捷键，自然说话，你的话会被实时转写、AI 润色，然后自动输入到当前光标所在的任意 App 里 —— 不用切换窗口，不用复制粘贴。

> English: [README.md](README.md)

## 功能特性

- **随处听写** —— 在任意 App（文档、Slack、邮件、浏览器、终端……）里把语音变成文字。
- **实时流式转写** —— 悬浮语音条实时显示识别结果。
- **AI 润色** —— 可选，通过大模型去除口头语、纠错、排版。
- **翻译** —— 说一种语言，自动注入另一种语言。
- **历史与统计** —— 可搜索的历史记录，以及按日 / 周的字数统计。
- **本地 / 线上双引擎** —— 本地 SenseVoice + 本地大模型可完全离线；也支持 BYOK 接入云端 API。
- **BYOK** —— 自带 API Key，密钥仅保存在本机。

## 环境要求

- macOS 14+（Apple Silicon）
- Xcode Command Line Tools（需要 `swiftc`）

## 构建

```bash
./build.sh
```

脚本会用 `swiftc` 编译全部 Swift 源码、生成 App 图标，并输出 `NoType.app`。无需 Xcode 工程或 SPM。

## 使用

1. 启动 **NoType**。
2. 按提示授予权限：
   - **麦克风** —— 用于录音。
   - **辅助功能** —— 用于把文字注入当前 App。
   - **输入监控** —— 用于全局快捷键（可选，自定义快捷键时需要）。
3. 按下全局快捷键（默认 **Fn**）开始 / 停止听写。
4. 转写（以及可选润色）后的文字会直接插入当前光标处。

### 配置引擎

在「设置」中切换本地 / 线上引擎：

- **语音识别（ASR）**
  - 本地：SenseVoice（sherpa-onnx，离线，约 166MB 模型）。
  - 线上：火山引擎（豆包）流式识别，或自定义。
- **AI 润色（LLM）**
  - 本地：qwen2.5:7b（离线，约 4.7GB）。
  - 线上：OpenAI、DeepSeek、通义千问、Moonshot（Kimi），或任意 OpenAI 兼容接口。

### 快捷键

- **Fn** —— 听写（按一下开始，再按一下结束）。
- 可在设置中自定义全局快捷键（`⌥A`、`⌘1`、`⌃Space` 等），并绑定不同 Prompt（听写 / 翻译）。

## 技术栈

- Swift + SwiftUI + AppKit
- 直接用 `swiftc` 编译（无 Xcode / SPM）
- AVAudioEngine 录音（16kHz PCM）
- 文本注入：剪贴板 + 模拟 `⌘V`（需要「辅助功能」权限）
